# 个人智能体项目工作手册

## 目标

构建一个 Windows 优先、中文语音优先、本地可控的个人智能体。它保留 HoloJarvis 的中文语音与 HUD，并独立吸收其他项目的通用优点，不复制闭源实现。

## 不可破坏的原则

1. 使用 Python 3.12 和项目 `.venv`。
2. 高风险操作必须经过代码层权限和确认，不能只依赖提示词。
3. 文件操作默认限制在 `workspace/`。
4. Shell、MCP、发送消息、电源与删除默认关闭。
5. 本地数据是否发送给云模型必须可见、可控。
6. 每个非平凡变更至少保留一个可运行检查。
7. 优先复用标准库和现有模块，不为未来需求预建框架。

## 当前安全开关

默认全部关闭；确认风险后按需设置：

```powershell
$env:JARVIS_ENABLE_DANGEROUS_TOOLS = "1"
$env:JARVIS_ENABLE_SHELL = "1"
$env:JARVIS_ENABLE_MCP = "1"
$env:JARVIS_WORKSPACE = "D:\\你的安全工作区"
$env:JARVIS_CLOUD_MEMORY = "core,project"
```

危险工具启用后仍不会立即执行：系统会要求用户在下一轮明确回复“确认执行”。确认只对当前待执行操作生效，其他输入会取消它。
